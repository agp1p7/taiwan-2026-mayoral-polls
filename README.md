# 2026 年全台六大直轄市近 3 個月市長民調整理

本專案彙整 2026 年 8 月 16 日至 2026 年 11 月 16 日（2026 年九合一選舉投票日前 10 日民調封關前夕）全台六大直轄市（臺北市、新北市、桃園市、臺中市、臺南市、高雄市）公開市長民意調查資料，重點比較**同一家機構多次調查之前後變化**，並附上各次調查之**抽樣結構說明**（市話、手機雙底冊、網路問卷、混合抽樣與 AI 虛擬模擬）。

## 檔案說明
- `index.html`：六大直轄市獨立圖表＋表格互動式網頁（含同機構領先差距走勢圖、單波機構獨立圖例長條圖及篩選切換）
- `six-special-municipalities-polls.md`：Markdown 格式完整民調與抽樣結構對照文件
- `.nojekyll`：啟用 GitHub Pages 純靜態檔案部署

## 資料與方法學原則
1. **同機構比較原則**：僅針對同一家執行機構於近 3 個月內連續發布 2 波（含）以上之調查計算支持度與差距增減；不同機構因抽樣母體、拒訪處理及加權模型差異，不跨機構換算趨勢。
2. **單波獨立標註**：近 3 個月查無同機構第 2 波之調查，皆以獨立幾何圖例與單波標籤區隔呈現。
3. **法規備註**：依中華民國《公職人員選舉罷免法》第 53 條，2026 年 11 月 28 日投票日前 10 日起不得發布、報導、散布、評論或引述任何有關候選人或選舉之民意調查資料。
